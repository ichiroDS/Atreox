The mono overline kicker — renders `// CHILDREN` in uppercase JetBrains Mono, brand cyan, wide tracking (the `.overline` class). Marks the start of every section, sitting above a `SectionHeading`.

```jsx
<SectionBadge>Pricing</SectionBadge>      // renders: // PRICING
<SectionBadge>Who it's for</SectionBadge>
```
