The slashed-A brand mark — an inscriptional serif A cut by a blade swoosh, self-contained SVG with brand-cyan gradients and glow. Transparent background; sized by `height` (width follows the glyph's aspect ratio automatically).

```jsx
<LogoMark />              // 24px — default
<LogoMark height={22} />  // navbar size (site's own usage, next to <Wordmark />)
<LogoMark height={64} />  // hero / splash scale
```

Designed for dark backgrounds — the glow reads best on near-black.
